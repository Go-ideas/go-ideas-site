# Go-Ideas

Sitio corporativo de Go-Ideas. Versión privada para revisión.

Contenido estático en `dist/`. Abre `dist/index.html` para revisar el sitio.

Contacto: contact@go-ideas.com. Sin formulario ni servicio externo de envío.

Incluye capacidades, ecosistema de ocho etapas conectadas a la inteligencia del proyecto, soluciones y recorridos descriptivos sin datos de clientes. La ruta clientes está reservada para una futura plataforma; no implementa acceso.

No activar alojamiento ni modificar DNS sin aprobación. El dominio previsto es go-ideas.com.
